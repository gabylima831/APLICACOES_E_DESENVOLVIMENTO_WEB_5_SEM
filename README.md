Aula 24/03

ATIVIDADE EM DUPLA 

- Um membro da dupla cria um repositório no github.
- Cada dupla deve implementar um ambiente de desenvolvimento colaborativo.
- A dupla deve criar uma página de card, com um card de cada membro, usando grid e um arquivo de estilo css.
- Fazer o primeiro commit com os arquivos iniciais básicos, deve-se realizar mais dois commits, sendo um no meio e o outro no final. Após o primeiro commit, devem ser criadas duas branches:
    . Conteúdo -> HTML
    . Estilo -> CSS
